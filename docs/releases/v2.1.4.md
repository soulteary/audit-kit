# audit-kit v2.1.4

This patch updates `secure-kit/v2` to v2.1.4. `MaskEmail`, `MaskPhone` and the
corresponding `MaskDestination` branches inherit its Unicode code-point masking
fix. ASCII and short-input behavior remains unchanged. Other audit masking
helpers are not changed by this dependency update.

## Upgrade and rollback

```sh
go get github.com/soulteary/audit-kit/v2@v2.1.4
```

Rebuild applications to receive the dependency update. Public APIs, record JSON,
SQL schemas, Redis formats and filter behavior remain unchanged; no storage,
credential or namespace conversion is required. Existing records are not
rewritten. Non-ASCII masked values written after upgrade may differ from earlier
values; masking is not anonymization or a stable identity key.

For a code rollback, restore the application's pre-upgrade `go.mod` and `go.sum`
and rebuild. Downgrading only audit-kit may leave secure-kit v2.1.4 selected by
Go minimal version selection. A minimal consumer can explicitly request both:

```sh
go get github.com/soulteary/audit-kit/v2@v2.1.3 github.com/soulteary/secure-kit/v2@v2.1.3
go list -m github.com/soulteary/audit-kit/v2 github.com/soulteary/secure-kit/v2
```

Verify the complete application graph: another dependency may require a newer
secure-kit. Do not claim earlier masking behavior unless v2.1.3 is actually
selected. Rolling back code never rewrites existing audit rows.
Keep the same application storage configuration and verify ordinary record
write/read behavior in an isolated environment before rollout.
