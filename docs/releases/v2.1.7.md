# audit-kit v2.1.7 (unreleased)

This candidate refreshes the database drivers used by the test and integration
test suites, together with SQLite's indirect requirements.

| Module | Previous | Candidate |
| --- | --- | --- |
| `github.com/go-sql-driver/mysql` | v1.10.1 | v1.10.2 |
| `modernc.org/sqlite` | v1.62.0 | v1.63.0 |
| `modernc.org/libc` | v1.80.1 | v1.82.13 |
| `modernc.org/memory` | v1.12.1 | v1.13.0 |

The Go requirement remains 1.27.4 and `secure-kit/v2` remains v2.1.5. This
candidate contains no library source changes. Applications continue to register
their own database drivers.

After publication:

```sh
go get github.com/soulteary/audit-kit/v2@v2.1.7
```

For rollback, restore the application's previous `go.mod` and `go.sum`, then
rebuild. Downgrading audit-kit alone may leave newer dependencies selected by
another requirement in the application.
